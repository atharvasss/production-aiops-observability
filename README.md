
# Production Observability & AIOps Platform

**Prometheus · Grafana · ELK · Python · AIOps**

A production-style observability platform that combines metrics, logs and intelligent analysis to detect abnormal behavior and support faster incident investigation.

## Architecture

Application  
→ Metrics → Prometheus → Grafana  
→ Logs → Elasticsearch → Kibana  
→ Python AIOps Engine  
→ Anomaly Detection + Log Analysis + Incident Correlation

## What I Built

- Implemented centralized monitoring using Prometheus and Grafana.
- Centralized application logs using Elasticsearch and Kibana.
- Developed Python-based anomaly detection and log analysis workflows.
- Correlated monitoring signals to identify potential incidents.
- Generated structured incident-analysis results for Root Cause Analysis.
- Validated the platform using simulated application failures and abnormal behavior.
